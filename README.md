### テーマ
async/awaitってなんで必要なの？

Q：GitHub APIから情報を取るときに、async/awaitを使うのはなぜ？

A：GitHubから情報を取るのに少し時間がかかるため、情報が返ってくるのを待ってから次の処理をするために使います。

Q：なぜ情報が返ってくるのを待つ必要があるの？

A：情報が返ってくる前に次の処理をすると、まだデータがない状態で処理してしまう可能性があるからです。

Q：今回のコードでは、どの部分で待っているの？

A：fetchでGitHubに情報を取りに行き、awaitを使ってその結果が返ってくるのを待っています。
